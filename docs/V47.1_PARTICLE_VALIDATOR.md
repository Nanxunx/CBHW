# ModelPort V47.1 Particle Semantic Validator


## Branch

feature/v47-particle-validator


## Base

v47.0-effect-validator-framework


## Goal

Add semantic validation layer for M2 particle systems.

The validator does not modify conversion output.


## Design


Current pipeline:


WotLK M2 Reader

        |

        v

Particle Writer

        |

        v

Classic M2 Writer


New validation layer:


WotLK M2 Reader

        |

        +---- Particle Validator

        |

        v

Validation Report



## Validation Targets


### ParticleEmitter

- emitter count
- texture reference
- sequence reference
- lifetime
- emission rate


### Texture

- texture index
- texture lookup
- missing texture risk


### Rendering

- alpha
- blend mode
- color


### Animation

- sequence availability
- animation reference


## Development Rule


Do not modify ParticleWriter until validation results are available.
