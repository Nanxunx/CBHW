# V47.1 Particle Validator Design

## Goal

Add semantic validation for M2 particle emitters.

Validation is separated from conversion.

Existing ParticleWriter remains unchanged.

# Validation Scope


## 1. Particle Emitter

Validate:

- particle count
- record existence
- record bounds


---

## 2. Texture Reference

Validate:

- texture index exists
- texture lookup is valid
- referenced texture is available


---

## 3. Alpha Validation

Validate:

- alpha range
- transparency values


Expected:

0.0 <= alpha <= 1.0


---

## 4. Blend Mode

Validate supported modes:

- opaque
- alpha
- additive
- modulate


Unknown modes produce warnings.


---

## 5. Animation Reference

Validate:

- sequence id
- animation track reference
- external animation lookup


---

# Design Rules


## Rule 1

Do not modify:

- ParticleWriter.cpp
- ClassicM2Writer.cpp
- Golden pipeline


---

## Rule 2

Validator failures do not stop conversion.


---

## Rule 3

Each validation issue contains:

- code
- severity
- message


Example:

PARTICLE_TEXTURE_MISSING

PARTICLE_ALPHA_INVALID

PARTICLE_BLEND_UNKNOWN


---

# Validation Issue Format


Each issue contains:


Code:

PARTICLE_TEXTURE_MISSING


Severity:

INFO

WARNING

ERROR


Message:

Emitter references invalid texture index


---

# Testing Strategy


Unit tests cover:

- valid particle emitter
- invalid particle count
- missing texture reference
- invalid alpha value
- unknown blend mode
- invalid animation reference


CTest:

ctest --test-dir build-v46 -C Debug -R particle_validator
